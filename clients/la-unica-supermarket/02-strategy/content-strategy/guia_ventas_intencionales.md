## 🛒 CARRITO LOCO - Rifa de $300

### ¿Qué es el Carrito Loco?

**CONCEPTO:** Los clientes se registran en tienda para participar en la **RIFA de un mercado de hasta $300 gratis**.

Es una **activación en tienda** que:
1. Genera base de datos de clientes
2. Aumenta tráfico a la tienda
3. Crea engagement en redes (anuncio de ganadores)
4. Fideliza clientes que regresan a ver si ganaron

### Script en Caja - Registro

```
"¿Ya se registró para el Carrito Loco? Esta semana rifamos un mercado
de $300 gratis. Solo necesito su nombre y teléfono."
```

**Si el cliente pregunta:**
```
"Es una rifa. Se registra hoy y el [día] anunciamos al ganador.
Si gana, escoge hasta $300 de lo que quiera de la tienda. ¡Gratis!"
```

### Script en Entrada

```
"¡Bienvenido a La Única! ¿Ya se anotó para el Carrito Loco?
Estamos rifando un mercado de $300. La mesa de registro está [ubicación]."
```

### Después de la Rifa

**Para el ganador (redes sociales):**
```
"¡FELICIDADES a [nombre]! 🎉 Ganador del Carrito Loco de esta semana.
¿Quieres ser el próximo? Ven a La Única y regístrate. 📍 Independence Ave"
```

**En tienda después de rifa:**
```
"Ya anunciamos al ganador de esta semana. ¿Quiere registrarse para la próxima?"
```

## 🎯 ESTRATEGIA ANCLA: Carnicería + Comida Preparada

Estos dos departamentos son los que **más mueven gente** a la tienda.

### Flujo de Venta Cruzada

```
                    CARNICERÍA (63% margen)
                         ↕️
        ←── Cross-sell ←── Cliente ──→ Cross-sell ──→
                         ↕️
                   COMIDA PREPARADA
                         ↓
                   CAJA (Upsells finales)
                   - Tamales (temporada)
                   - Flan/postres
                   - Tortillas
                   - Registro Carrito Loco
```

### Tácticas

1. **Carnicería → Comida Preparada:**
   - Cliente indeciso en carnicería → "Lo tenemos ya preparado"

2. **Comida Preparada → Carnicería:**
   - Cliente satisfecho → "Ese corte está en oferta si lo quiere hacer en casa"

3. **Ambos → Caja:**
   - Upsell final de complementos y registro Carrito Loco

## ❌ LO QUE NUNCA HACER

1. **NO presionar** - Si dicen no, respeta la decisión
2. **NO repetir** la misma oferta dos veces
3. **NO ofrecer** si el cliente tiene prisa evidente
4. **NO mentir** sobre ofertas o precios
5. **NO ignorar** al cliente por hablar con compañeros

---

## ✅ LO QUE SIEMPRE HACER

1. **Sonreír** y hacer contacto visual
2. **Usar "usted"** para respeto
3. **Mencionar el beneficio** ("le sale más barato", "está recién hecho")
4. **Agradecer** siempre la compra
5. **Ser genuino** - Si no te gusta un producto, no lo recomiendes
6. **Invitar a registrarse** para el Carrito Loco
